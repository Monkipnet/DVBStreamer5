# DVBStreamer5 V10.8.588 — перенос плиток между серверами через правый клик

## RU

Теперь поддерживаются **обычные потоковые плитки** и **WISI EPG**.

1. На исходном сервере нажмите **правой кнопкой** по плитке → **Копировать плитку**.
2. На целевом сервере нажмите **правой кнопкой** по пустому месту на панели → **Вставить как новую плитку**.
3. Если браузер запретил Clipboard API (обычно для HTTP), вручную скопируйте текст из появившегося окна и вставьте в диалог на целевом сервере через **Ctrl+V**.
4. Нажмите **Проверить** и прочитайте предупреждения. Затем подтвердите **Создать плитку**.
5. Новая плитка создаётся остановленной с новым ID и выключенным автозапуском; до запуска проверьте IP, порты, DVB-тюнер, GPU, CAM и XMLTV.

### Безопасность

Копируется **только одна** плитка, а не глобальный конфиг или учётные записи сервера. На стороне исходного сервера удаляются: SRT-пароли и stream IDs, ключи HLS, CA/CAM-привязка, XMLTV source ID, IP интерфейсов, override авторизации, автозапуск, HLS archive path. Из HTTP/SRT URI удаляются userinfo, query и fragment, где могут находиться токены. **Если секрет находится прямо в пути URL, администратор должен проверить скопированный JSON перед переносом.** Устройства и сетевые интерфейсы переназначаются вручную. Исходные работающие плитки не останавливаются.

Запись использует отдельный API, не полный `handleSaveConfig()`: сохраняется только новая StreamConfig либо EpgUdpOutputConfig; существующие EPG UDP отправители не перезапускаются из-за вставки.

Для WISI EPG при переносе сохраняются каналы, но при несуществующем stream_id или XMLTV source_id отображается предупреждение. Новый выход WISI выключен до ручного запуска.

В первой версии **MPTS-карточки не поддерживаются**: их перенос требует отдельной перепривязки сервисов.

### Ограничения

* Chromium Clipboard API требует HTTPS или доверенного контекста; для HTTP используйте ручной Ctrl+C/Ctrl+V.
* Созданный поток намеренно не запускается автоматически. HTTP/SRT listener, GPU, декодеры и настройки CAM необходимо проверить перед ручным стартом.
* При вставке не копируются настройки авторизации или серверные секреты. Перенос незашифрованного входного URL не гарантирует, что URL не содержит токена в пути; администратору следует проверить текст.
* Все новые сообщения интерфейса переведены на RU/EN/HR/DE.
