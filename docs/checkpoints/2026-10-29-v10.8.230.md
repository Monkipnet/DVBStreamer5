## Известные незакрытые проблемы

1. NVIDIA NVDEC→NVENC: 1080i H.264 → 720p с `deinterlace=bob` уменьшает полосы, но цветность UV и широкие цветные горизонтальные полосы остаются повреждёнными. При `DVBSTREAMER5_NVDEC_DIAG_CHROMA=neutral` чёрно-белое изображение чистое. В тесте `DVBSTREAMER5_NVDEC_UV_PROBE=1` исходные и целевые пробы UV совпали (U,V ~126–127), но NVDEC также сообщал `cuvidDecodeStatus_Error_Concealed` (status=9); причина не установлена. Не считать zero-copy пригодным для production до проверки цветности. Безопасный fallback: явно выбранный `Ittiam` с NVENC.
2. Синхронизация A/V после mux-fix не подтверждена. Журнал при SID 132: `av_delta_ms` около +440…+498, `vq` около 29–50, `aq=0`, растёт `late_audio`. SID 122: `av_delta_ms` около -450…-498, `vq=0`, `aq` около 211–238, растёт `late_video`. `drop_video=0 drop_audio=0` на момент замеров. Эти значения диагностические, не прямое измерение perceptual lip-sync. Нужен анализ входного PTS/PES и выходного временного базиса; нельзя слепо отбрасывать кадры/менять A/V offset.
3. Экспериментальные systemd Environment-override находятся **на сервере**, а не в Git. Последний присланный процесс имел `DVBSTREAMER5_NVDEC_UV_PROBE=1`, `DVBSTREAMER5_NVDEC_VPP_PROBE=1`, `DVBSTREAMER5_NVDEC_VPP_MODE=bob`, `DVBSTREAMER5_NVDEC_SAFE_COPY=1`, `DVBSTREAMER5_NVDEC_DIAG_CHROMA=off`, `DVBSTREAMER5_DISABLE_NVIDIA_ZERO_COPY=0`. Перед production-тестами проверить и отключить ненужные probes; сохранить отдельно конфигурацию `/etc/dvbstreamer5` и `/etc/systemd/system/dvbstreamer5.service.d`.

## Команды сборки

```bash
git switch main
git pull --ff-only origin main
cmake -S . -B build-release -DCMAKE_BUILD_TYPE=Release -DDVBSTREAMER5_ENABLE_NVENC=ON -DDVBSTREAMER5_ENABLE_VAAPI=ON -DDVBSTREAMER5_ENABLE_INTEL_QSV=ON
cmake --build build-release --parallel 2
bash scripts/make_portable_linux_bundle.sh --build-dir build-release --binary build-release/DVBStreamer5 --output-dir dist/DVBStreamer5-linux-x86_64 --with-oscam --archive
```
