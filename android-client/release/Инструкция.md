# DVBStreamer5 Remote 1.4

Официальное Android-приложение DVBStreamer5. Android 8.0+ (API 26), target/compile SDK 35, телефоны и планшеты, портретная и альбомная ориентация. Без сторонних библиотек в APK. Единственное разрешение — INTERNET.

## Исправление меню в 1.4

Меню веб-панели ограничивается видимой областью экрана и прокручивается по вертикали. Положение пересчитывается при открытии подменю, повороте, изменении размера окна и появлении клавиатуры. На узком экране поля форм и элементы шапки переносятся. Нативное меню ⋮ заменено прокручиваемым диалогом с переносом длинных надписей; формы входа и пароля архива также прокручиваются. Исправление загружается из assets/viewport-fix.js в WebView для выбранного сервера и не меняет код или настройки сервера.

Проверено 30 сценариев с реальной HTML-разметкой актуальной серверной версии: экраны 320×480, 360×640, 640×320, 800×1280, 1280×800, увеличенный текст, раскрытые подменю, доступность нижних пунктов, формы и изменение размера до 320×240. Это браузерные проверки, не тесты на физическом Android.

Для повторения браузерных проверок на Linux: установите Node.js, Chromium и тестовую зависимость playwright-core (`npm install --no-save playwright-core`), затем `node scripts/test_viewport.cjs /path/to/DVBStreamer5/src/http/HttpServerWebUi.inc`. При необходимости задайте CHROMIUM_PATH.

## Локализация

Русский, English и Deutsch. Кнопка «Язык / Language» / Language / Sprache в настройках приложения позволяет выбрать язык или использовать системный. Для других системных языков используется английский. Выбор сохраняется, включается в обычный и зашифрованный экспорт. Архивы версии 1.2 без поля language поддерживаются (системный язык). Язык серверной веб-панели выбирается отдельно в самой панели: её переводы предоставляет установленная версия сервера.

## Возможности

- Выпадающий список серверов на главном экране и внутри подключения.
- Профили: название, HTTP/HTTPS, IP/имя, отдельный порт, логин, пароль и автологин. Создание, изменение, удаление.
- Встроенная веб-панель: доступные в вашей версии сервера управление потоками, DVB, мониторинг и настройки. Панель загружается с вашего сервера, не входит в APK и не подменяется макетом.
- Автологин через POST /api/panel/login с установкой cookie-сеанса. Для серверов, отвечающих 404/405 на этот API, предусмотрен HTTP Basic Auth. Неверные данные не перебираются автоматически.
- Секреты в профилях зашифрованы AES-256-GCM с ключом Android Keystore. При отключении автологина пароль профиля удаляется.
- Масштаб текста 80/100/125/150%, сохраняется в настройках приложения.
- Экспорт/импорт через системный выбор файла, без доступа ко всему хранилищу.
- Обычный JSON-экспорт не содержит паролей и отключает автологин в экспортированной копии.
- Зашифрованный перенос с паролями: PBKDF2-HMAC-SHA256 (210000 итераций), случайная соль 16 байт, AES-256-GCM. Для импорта на другом устройстве нужен пароль архива.
- Импорт сначала проверяет весь архив и показывает подтверждение замены. Ограничение: 100 серверов, файл до 2 МБ. Настройки самого сервера через этот архив не меняются.
- Тёмные цвета аналогичны веб-панели DVBStreamer5. Иконка заменена на оригинальный PNG 1254 × 1254 из пользовательского RAR-архива; отступ адаптивной иконки сохраняет голубую рамку.

## Установка и подключение

1. Установите DVBStreamer5-Remote-1.4.apk, разрешив установку из выбранного файлового менеджера при запросе Android.
2. Добавьте сервер: IP/имя без протокола, порт (обычно 9000), выберите HTTP или HTTPS.
3. При необходимости укажите логин/пароль и включите автологин. Выберите сервер в списке, нажмите «Подключиться».
4. Телефон должен иметь сетевой доступ к серверу (Wi-Fi/LAN/VPN). Адрес 127.0.0.1 на телефоне указывает на сам телефон, не на сервер.
5. В меню ⋮ доступны настройки подключения, масштаб текста и удаление локальных сеансов. Изменение поля порта профиля не меняет порт в конфигурации DVBStreamer5.

## Ограничения и проверка

APK собран и подписан локальным ключом. Проверены minSdk 26, targetSdk 35, подписи v2/v3, zipalign, формат APK и компиляция. Пройдены 14 проверок адресов, 25 проверок криптографии/архива/портов 18 проверок выбора языка и переноса его в архиве, полнота 116 строк для каждого из трёх языков и сетевой тест автологина с mock-сервером (успех, cookies, ошибка пароля, запрет перехода по redirect, старый API).

Установка и интерфейс на реальном Android-устройстве/эмуляторе, работа Android Keystore на устройстве и управление живым сервером пока не проверены. Функции и адаптивность самой панели зависят от установленной серверной версии и Android System WebView. Рекомендуется обновить Android System WebView.

Предпросмотр видео зависит от поддержки кодеков WebView; специальный видеоплеер и фоновое воспроизведение не добавлялись. Полноэкранный видеорежим не реализован. Серверные загрузки http(s) открываются во внешнем браузере, где может понадобиться отдельный вход. Ссылки blob: для серверного экспорта пока не поддерживаются; импорт/экспорт настроек приложения работает отдельно, нативно.

Доступ по HTTP передаёт логин/пароль без шифрования: используйте доверенную сеть, VPN или HTTPS с действительным доверенным сертификатом. Проверка TLS не отключается. Файл зашифрованного архива нельзя восстановить без его пароля. Нешифрованный экспорт содержит адреса и логины, хотя не содержит паролей. Архив настроек не содержит cookies веб-панели.

После импорта локальные cookie-сеансы удаляются. После удаления данных или переустановки приложения ключ Android Keystore может стать недоступен: восстановите настройки из зашифрованного архива. Резервное копирование приложения Android отключено.

## Исходный проект и сборка

Репозиторий сервера: https://github.com/Monkipnet/DVBStreamer5
Контракт API изучен на commit f5a9586d808723e2567accd9b2e66c451362134e.
Серверный C++-код в APK не включён.

Откройте эту папку в Android Studio с JDK 17 или 21. Для Android Gradle Plugin 8.7.3 используйте Gradle 8.9 и Android SDK Platform 35. Gradle wrapper в архив не включён. Через установленный Gradle: `gradle assembleDebug`. Для собственной release-подписи используйте Build → Generate Signed Bundle / APK. Новая подпись отличается от подписи предоставленного APK; для замены приложения другой подписью понадобится удалить предыдущую установку (сначала экспортируйте настройки).

`tests/` содержит автономные JVM-проверки, запускаемые с org.json 20240303; это тестовая зависимость, не зависимость приложения. Для запуска: `./scripts/test.sh` (нужны JDK с javac, Python 3 и curl; JSON-библиотека загружается с Maven Central).

Логотип: исходный PNG, предоставленный пользователем. Файл встроен без перерисовки.
