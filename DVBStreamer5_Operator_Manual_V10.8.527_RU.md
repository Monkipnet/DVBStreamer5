# Руководство оператора DVBStreamer5

**Редакция:** V10.8.527 · 14 ноября 2026 года  
**Проект:** [Monkipnet/DVBStreamer5](https://github.com/Monkipnet/DVBStreamer5) · `main`

Практическая инструкция для операторов вещания, перенесённая из одноимённого 14-страничного PDF. Содержание отражает редакцию V10.8.527; в более новых версиях отдельные подписи интерфейса могут отличаться. Схемы в PDF иллюстративные, не скриншоты.

## 1. Вход и навигация

*Где найти: Браузер / веб-панель DVBStreamer5*

DVBStreamer5 управляется через браузер. Оператору не требуется работать в терминале: каналы, источники, выходы и дополнительные модули доступны в веб-интерфейсе.

### Порядок действий

1. Откройте адрес панели, который выдал администратор. Типичная установка использует http://АДРЕС-СЕРВЕРА:9000/.
2. Введите свою учётную запись и пароль. Если установлен стартовый пароль, замените его при первом входе.
3. Откройте главную страницу с плитками каналов. Используйте меню для перехода к DVB, сетевому мониторингу, EPG, OSCam-mini и обновлениям.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| Главная | Плитки каналов, состояние и управление запуском. |
| Редактирование | Источники, выходы, резервирование и кодирование конкретного канала. |
| DVB / Транспондеры | Спутниковые настройки и общие ресурсы тюнеров. |
| Мониторинг | Показатели каналов, сетевые подключения и абоненты. |
| Системные разделы | EPG/XMLTV, дополнительные модули, настройки и обновления. |

> Доступность пунктов определяется правами учётной записи. Не изменяйте настройки чужих каналов без согласования.

## 2. Главная панель и плитки

*Где найти: Главная / плитка нужного канала*

Каждая плитка представляет отдельный канал или поток. На ней доступны действия запуска, остановки, редактирования и сведения о текущем источнике.

### Порядок действий

1. Найдите плитку по названию. При большом числе IP-каналов используйте их порядок отображения для ориентации.
2. Посмотрите состояние канала, активный источник и входной/выходной битрейт. Для DVB-источника доступны индикаторы LOCK, уровня и качества.
3. Нажмите «Редактировать», чтобы открыть свойства, или «Старт» / «Стоп» для управления только этой плиткой.
4. После изменения убедитесь, что плитка запущена и зрительский выход воспроизводит видео со звуком.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| Старт / Стоп | Запуск и остановка выбранной плитки. |
| Редактировать | Открывает параметры источников, выходов и транскодирования. |
| Auto Start | Автоматический старт после запуска сервера; для online-плиток возможны ограниченные повторные попытки после неожиданной остановки. |
| Входной / выходной битрейт | Показывает поступление и выдачу данных. |
| Активный источник | Показывает основной, резервный или файл замены. |

> «Стоп» на одной плитке не означает остановку всего DVBStreamer5. Сначала выберите нужный канал.

## 3. Создание и редактирование канала

*Где найти: Главная / добавление канала / редактирование плитки*

Редактор объединяет сведения о канале, входе, резервировании, выходах и транскодировании. Состав полей зависит от выбранного типа источника.

### Порядок действий

1. Откройте добавление канала либо «Редактировать» для существующей плитки.
2. Укажите понятное название канала и выберите тип входного источника.
3. Заполните адрес или параметры приёма. Для сетевого входа укажите URL/адрес и при необходимости порт; для DVB — транспондер и сервис.
4. При необходимости настройте резервный вход, выходные протоколы и обработку видео/аудио.
5. Нажмите «Сохранить». Если новые параметры требуют перезапуска плитки, примените их к этой плитке в удобное время.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| Название | Имя канала на главной панели. |
| Тип источника | DVB, UDP/RTP, HTTP/HTTPS, HLS, SRT, RTSP, RTMP или локальный файл — по доступным режимам. |
| URL / адрес / порт | Куда подключаться для приёма IP-потока. |
| Включить транскодирование | Обрабатывать видео и/или звук либо оставить режим копирования. |
| Выходы | Куда публиковать поток для приёмников и абонентов. |

> Сохранение настроек не всегда равно мгновенному применению всех параметров к уже работающему потоку.

## 4. Сетевые источники IPTV

*Где найти: Редактор канала / Источник / Вход*

В качестве входа можно использовать UDP/RTP, HTTP/HTTPS TS, HLS, SRT, RTSP, RTMP и файл, если соответствующий режим включён в сборке и конфигурации.

### Порядок действий

1. Выберите тип источника, соответствующий поставщику сигнала.
2. Вставьте точный URL либо адрес и порт. Для multicast учитывайте доступность соответствующей сети.
3. Для SRT выберите совместимый режим соединения и параметры подключения; исходный и принимающий узлы должны совпадать по режиму и порту.
4. Сохраните канал, запустите плитку и проверьте, что активен ожидаемый вход.
5. Если есть резерв, убедитесь, что он указан отдельно от основного адреса.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| UDP / RTP | Приём MPEG-TS по сети; возможен multicast. |
| HTTP TS | Непрерывный транспортный поток по HTTP/HTTPS. |
| HLS | Вход по плейлисту и сегментам. |
| SRT | Соединение Caller/Listener с параметрами совместимости и задержки. |
| RTSP / RTMP | Вход через соответствующий медиапротокол. |
| Файл | Чтение локально доступного медиафайла. |

> Не путайте URL источника с адресом выходного потока: они задаются в разных разделах.

## 5. Спутниковые каналы DVB-S/S2

*Где найти: DVB / Транспондеры / выбор тюнера и сервиса*

Спутниковый приём настраивается через оборудование и транспондер. Несколько сервисов одного транспондера могут использовать общий frontend.

### Порядок действий

1. Откройте раздел DVB и выберите доступный тюнер/frontend.
2. Укажите спутник или нужный транспондер: частоту, поляризацию, символьную скорость SR и остальные требуемые параметры.
3. При необходимости выберите DiSEqC, Unicable/JESS с правильной пользовательской полосой UB и частотой либо MIS/Stream ID.
4. Выберите нужный телевизионный сервис и привяжите его к плитке.
5. Сохраните настройки и проверьте в интерфейсе индикаторы LOCK, качества и уровня.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| Frontend | Физическое устройство приёма DVB. |
| Частота / SR / поляризация | Основные параметры транспондера. |
| DiSEqC | Переключение входов спутникового оборудования. |
| Unicable / JESS | Пользовательская полоса UB и её частота. |
| MIS / Stream ID | Выбор одного потока на многопотоковом транспондере. |
| LOCK / уровень / качество | Индикаторы состояния приёма. |

> Изменение настроек общего frontend может повлиять на другие каналы, использующие этот тюнер.

## 6. Основной и резервный источники

*Где найти: Редактор канала / Основной / Резервный источник*

Резервирование помогает продолжить вещание при недоступности основного источника. В поддерживаемых режимах вместо него может использоваться локальный файл замены.

### Порядок действий

1. Укажите основной источник и проверьте, что он работает.
2. Добавьте резервный URL или выберите локальный файл замены, если эта опция доступна.
3. Установите время ожидания переключения, чтобы краткое колебание сети не вызывало постоянные переходы.
4. Настройте возврат на основной источник после его восстановления, если это требуется.
5. Сохраните изменения. Проверяйте текущий источник прямо на плитке и воспроизведение на клиенте.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| Основной источник | Первый вариант получения сигнала. |
| Резервный источник | Альтернативный адрес при недоступности основного. |
| Файл замены | Локальный медиафайл в поддерживаемых режимах. |
| Порог переключения | Как долго ждать перед переходом на резерв. |
| Возврат на основной | Политика обратного переключения после восстановления. |

> Слишком короткое ожидание может приводить к частым переключениям. Проверяйте наличие видео и звука, а не только активность плитки.

## 7. Настройка выходов

*Где найти: Редактор канала / Выходы*

Один канал может передаваться зрителям через один или несколько поддерживаемых выходных протоколов. Выбирайте формат, соответствующий принимающему оборудованию.

### Порядок действий

1. Откройте настройки выходов выбранного канала.
2. Добавьте или включите необходимый протокол: UDP/RTP, HTTP TS, SRT, HLS или другой доступный режим.
3. Для адресного выхода укажите конечный IP-адрес и порт; для SRT — режим соединения и совместимые параметры.
4. Для HLS проверьте, что клиент использует правильный URL плейлиста.
5. При необходимости включите CBR или настройте параметры MPEG-TS, если они нужны принимающему оборудованию.
6. Сохраните настройки и проверьте поток на одном зрительском устройстве.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| UDP / RTP | Доставка MPEG-TS в локальную или multicast-сеть. |
| HTTP TS | Получение непрерывного TS по HTTP. |
| SRT | Передача с согласованными параметрами соединения и задержки. |
| HLS | Сегментированное вещание с плейлистом. |
| CBR | Поддержание заданного транспортного битрейта в поддерживаемых выходах. |
| SID / PID ремаппинг | Настройка идентификаторов транспортного потока, если требуется совместимость с приёмником. |

> Убедитесь, что адреса и порты соответствуют назначению, а multicast разрешён в вашей сети.

## 8. Транскодирование видео и аудио

*Где найти: Редактор канала / Транскодирование*

Видеосигнал можно передавать без перекодирования (Copy) или изменять кодек, размер, частоту кадров и битрейт. Аудио может копироваться либо кодироваться в другой формат.

### Порядок действий

1. Откройте настройки транскодирования выбранной плитки.
2. Если вход совместим с выходом и менять изображение не требуется, выберите Video Copy. Иначе выберите H.264 или другой поддерживаемый кодек.
3. Задайте разрешение, FPS, видеобитрейт и при необходимости профиль/предустановку.
4. Выберите видеоэнкодер: Auto, CPU, Intel QSV/VAAPI или NVIDIA NVENC — только при наличии соответствующего оборудования и драйверов.
5. Для звука выберите Audio Copy либо нужный аудиокодек; при необходимости настройте каналы и битрейт.
6. Сохраните настройки, перезапустите только тестовую плитку при необходимости и проверьте изображение и звук.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| Video Copy | Передача сжатого видео без перекодирования. |
| Audio Copy | Передача аудио без перекодирования. |
| CPU | Программное кодирование на процессоре. |
| Intel QSV / VAAPI | Аппаратное кодирование на совместимой Intel GPU. |
| NVIDIA NVENC | Аппаратное кодирование на совместимой NVIDIA GPU. |
| Размер / FPS / битрейт | Параметры выходного изображения. |

> «Auto» выбирает доступный backend, поэтому для осознанного выбора укажите CPU, VAAPI/QSV или NVENC явно. Доступность определяется системой.

## 9. EPG, XMLTV и субтитры

*Где найти: Меню / EPG / XMLTV; редактор канала / EPG / субтитры*

Электронная программа передач может поступать из DVB EIT либо внешнего файла XMLTV. Доступность и перенос EPG зависит от конкретного выходного формата.

### Порядок действий

1. Откройте раздел EPG / XMLTV.
2. Если используете внешний источник, добавьте адрес HTTP XMLTV и параметры его загрузки.
3. При наличии сопоставления каналов выберите, какой XMLTV-канал относится к какой плитке.
4. Запустите ручное обновление («Обновить сейчас»), если требуется получить данные сразу.
5. Для DVB-сервисов при необходимости включите передачу EIT на поддерживаемом выходе.
6. Если у сервиса есть DVB-субтитры и выход их поддерживает, включите соответствующую опцию.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| DVB EIT | Телепрограмма из DVB-потока. |
| XMLTV HTTP | Внешний источник телепрограммы. |
| Сопоставление каналов | Соединяет программу передач с конкретной плиткой. |
| Обновить сейчас | Ручное получение обновлённых данных. |
| DVB subtitles | Субтитры на поддерживаемых потоках и выходах. |

> После изменения EPG откройте программу передач на устройстве приёма: наличие XMLTV в панели не означает, что каждый выход его передаёт.

## 10. OSCam-mini и условный доступ

*Где найти: Меню / OSCam-mini / CAM*

Раздел условного доступа предназначен для настройки разрешённых карт и доступных CA-модулей. Права на приём защищённых программ должны быть у владельца оборудования.

### Порядок действий

1. Откройте OSCam-mini или соответствующий CAM-раздел в веб-панели.
2. Просмотрите состояние службы и список доступных readers.
3. Администратор может добавить локальный Phoenix/PCSC reader либо разрешённый удалённый Newcamd reader.
4. При необходимости задайте группы, CAID и Provider/Ident согласно параметрам вашей карты и подписки.
5. Сохраните настройки и включите соответствующий CA-источник для нужной плитки.
6. Для опытных пользователей отдельной плитки может быть доступен экспериментальный TSDecrypt; не включайте его без согласования.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| Readers | Подключённые картридеры и разрешённые удалённые источники. |
| Newcamd users | Учётные записи авторизованных клиентов. |
| Group | Связь readers с группами доступа. |
| CAID / Provider / Ident | Параметры системы условного доступа. |
| Keepalive | Поддержание соединения там, где поддерживается. |
| TSDecrypt | Альтернативный экспериментальный модуль при наличии в сборке. |

> Не передавайте другим операторам пароли, ключи доступа и экспортированные конфигурации. Настройки CA доверяйте уполномоченному администратору.

## 11. Мониторинг, абоненты и уведомления

*Где найти: Главная / Мониторинг / Сеть / Абоненты*

Оператор использует показатели веб-панели, чтобы контролировать вещание и активность клиентов, не подключаясь к консоли сервера.

### Порядок действий

1. Откройте мониторинг выбранной плитки или общий раздел сети.
2. Посмотрите входной и выходной битрейт, состояние источника и активность выходов.
3. Если доступны списки абонентов, выберите канал и просмотрите текущие подключения.
4. При использовании уведомлений настройте их в соответствующем разделе совместно с администратором.
5. При необходимости вернитесь к плитке и измените только относящиеся к ней настройки.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| Вход / выход | Показатели поступления и выдачи данных. |
| Абоненты онлайн | Текущие подключения к поддерживаемым выходам. |
| Сетевые интерфейсы | Отображение входных/выходных направлений и фильтров при наличии прав. |
| Уведомления | Сообщения о состоянии, если функция настроена. |
| Активный источник | Текущий основной, резервный или заменяющий вход. |

> Показатели отображаются согласно настройкам и возможностям установленной версии. Для решения оператора ориентируйтесь также на воспроизведение канала.

## 12. Настройки панели и обновления

*Где найти: Главное меню / Настройки / Проверка обновлений*

Веб-панель может предлагать настройку языка и темы, а также проверку доступной версии программы. Установка новой версии относится к действиям администратора.

### Порядок действий

1. В настройках панели выберите предпочитаемый язык, если переключатель доступен.
2. При необходимости выберите светлую или тёмную тему.
3. Для проверки версии откройте «Проверка обновлений» и сравните установленную версию с доступной.
4. Если панель предлагает «Обновить», согласуйте процедуру с администратором: во время установки вещание может прерваться.
5. Вернитесь на главную страницу и убедитесь, что привычные плитки и их настройки доступны.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| Русский / English | Язык интерфейса при наличии перевода. |
| Светлая / тёмная тема | Оформление веб-панели. |
| Проверка обновлений | Просмотр сведений о доступной версии. |
| Обновить | Запуск установки при наличии прав и предусмотренного механизма. |

> Простая проверка версии не устанавливает обновление. Не запускайте обновление без согласованного окна обслуживания.

## 13. Ежедневный порядок работы

*Где найти: Главная / каналы / при необходимости редактор*

Эта памятка помогает выполнять основные операции одинаково и безопасно.

### Порядок действий

1. Войдите в панель и проверьте состояние плиток, за которые отвечаете.
2. Убедитесь, что у важных каналов выбран ожидаемый источник и имеются входной и выходной потоки.
3. При изменении параметров открывайте редактор конкретного канала и сохраняйте только нужные настройки.
4. После запуска, остановки или изменения канала проверьте его воспроизведение на клиентском устройстве.
5. При работе с общими тюнерами, CA и обновлениями соблюдайте порядок согласования с администратором.

### Основные элементы

| Элемент / поле | Назначение |
|---|---|
| Добавить канал | Создать новую плитку с входом и выходами. |
| Изменить канал | Настроить конкретную плитку без массового изменения остальных. |
| Старт / Стоп | Управлять состоянием одного выбранного канала. |
| Резервирование | Выбрать основной/резервный вход и политику возврата. |
| Проверить обновление | Узнать о версии, не устанавливая её автоматически. |

> Основное правило: изменяйте только тот канал и тот параметр, ради которого открыли редактор. Передайте оператору следующей смены сведения о важных изменениях.
